金叉死叉策略
一、做空 SHORT 完整规则
1. 做空预判信号（预判死叉）
核心条件（全部满足，方可直接开空）
- 当前价格 < EMA200
- EMA50 > EMA200
- |EMA50 - EMA200| / EMA200 < 0.18%（EMA50与EMA200极度贴近）
2. 执行规则
- 所有条件全部满足时，严格按做多方向开仓，不做额外主观过滤
二、做多 LONG 完整规则
1. 做多预判信号（预判金叉）
核心条件（全部满足，方可直接开多）
- 当前价格 > EMA200
- EMA50 < EMA200
- |EMA50 - EMA200| / EMA200 < 0.18%（EMA50与EMA200极度贴近）
2. 执行规则
- 所有条件全部满足时，严格按做空方向开仓，不做额外主观过滤
