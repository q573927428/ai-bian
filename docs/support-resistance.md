# 实时支撑阻力

所有策略默认按主周期补充结构背景；支撑阻力区域接入统一指标预计算，当前配置每5分钟刷新，不额外请求交易所。
指标看板打开时每15秒读取区域缓存，只按最新本地价格更新距离和盘中状态，关闭后停止。
首次访问或区域缓存满5分钟时兜底构建一次，后续请求共享结果。区域计算时间与价格更新时间分别保留。
五周期默认参数组合按交易对去重注册；自定义策略参数单独缓存。K线盘中更新不会清空区域缓存。

## 计算口径

- 默认回看96根已收盘K线，左右各3根确认摆动点；未收盘K线不能确认摆动点。
- 同类摆动点按价格聚合，区域总宽不超过已收盘ATR14的0.5倍；单次已确认摆动点作为候选显示“待验证”，2次以上为多次触碰区域。
- 收盘穿越区域远端并超过0.1 ATR缓冲后，该区域失效；不会自动转换成反向区域。
- 盘中穿越只显示待确认；最新已收盘K线穿越既有区域显示收盘确认，均不等于回踩确认。
- 已收盘新摆动点、区域失效及收盘突破状态随区域计算刷新，正常情况下最多延迟5分钟。
- 距离按本次参考价格到区域近端计算；处于区域内时为0。未识别到区域返回null，不代表没有障碍。
- 连续历史不足、时间断档、无有效价格或零波动返回数据不足。
- AI使用扫描价格，看板使用最新本地K线收盘价；两者共用算法，刷新时刻不同可能产生不同距离。

## 策略参数

可在策略indicators中设置下列配置；不配置时使用默认值，显式enabled=false可停用AI结构输入。
看板统一使用默认参数，便于同周期横向比较。

```json
{
  "id": "support-resistance",
  "type": "SupportResistance",
  "enabled": true,
  "timeframes": ["15m"],
  "params": {
    "lookback": 96,
    "pivotLeft": 3,
    "pivotRight": 3,
    "mergeDistanceATR": 0.5,
    "minTouches": 1,
    "breakoutBufferATR": 0.1
  }
}
```

当前结构始终跟随策略主周期；不单独使用该配置的timeframes切换周期。

## 数据流与历史保存

SupportResistanceCalculator → IndicatorsHub实时分支 → StrategyEngine → AI提示词及分析日志。
AI信号携带supportResistance；开仓时保存为entrySupportResistance，先随活跃持仓落盘，平仓时复制到交易历史。
交易记录展开后显示冻结快照，旧订单不回填当前行情。

此次仅补充数据和解释背景，不新增自动拒绝开仓的硬规则。
