# 环境置信度 v1

置信度衡量市场环境对策略分析方向的支持程度，不表示胜率。评分衡量入场规则匹配度；风险等级独立评估波动和位置风险。未完成K线、K线进度不参与置信度扣分。

## 共享规则

不设置策略类型或环境模板，所有策略统一按当前交易方向计算五周期支持度。

规则统一位于 `app/utils/environment-confidence.ts`，看板和服务端直接复用。服务端通过指标中心读取五周期 ADX(14)、MACD(12,26,9)，不依赖打开看板，不请求 OI 或社区情绪。

## 五周期结构

周期依次为5m、15m、1h、4h、1d。DI方向与MACD柱方向相同才保留多空方向；只有DI与MACD同时增强才称“增强”。“减弱”沿用看板展示语义，仅表示没有同时增强，也可能包含持平。方向冲突是中性，缺失是未知，两者分开。

1d/4h判断背景、1h判断承接、15m/5m判断短线。结构标签沿用看板的趋势延续、短线回调、反转观察、承接观察及背景分歧分类；分数根据各周期方向计算，不直接把标签映射成统一分数。

每个周期对指定方向：同向增强100、同向减弱80、中性50、反向减弱20、反向增强0，多空对称。“减弱”指未同时增强，不代表两个指标都在衰退；反向减弱只表示反向压力缓和。5m/15m/1h/4h/1d内部权重统一为10/20/30/20/20，即短线30%、中间承接30%、大周期背景40%。

回调或反转是否适合入场、是否达到触发点仍由策略规则判断；不因为策略希望逆势入场就把反向周期计为支持。

## 市场支持与相对强弱

市场范围为系统已选交易对，不代表整个币安市场。使用市场广度同一固定快照，5m、15m、1h、4h、24h五个窗口，权重依次为10%、20%、30%、25%、15%。市场支持度与相对强弱使用同一组窗口权重。

市场广度另提供滚动24h涨跌幅：以快照时间向下对齐5分钟后减去24小时，读取对应本地5m K线开盘价作为基准，与当前价格比较。前后端共用该基准，不使用ticker的24h涨跌幅，也不使用当日日线开盘价；缺基准时保留未知。AI采用固定快照，页面随实时价格重算，基准随快照刷新。

单窗口市场支持：

| 状态 | 支持分 |
| --- | --- |
| 同向占比≥65%，中位数同向 | 100 |
| 同向占比≥55%，中位数同向 | 75 |
| 反向占比≥65%，中位数反向 | 0 |
| 反向占比≥55%，中位数反向 | 25 |
| 其他，包括持平与方向冲突 | 50 |

占比分母含有效持平样本，排除缺失样本。

相对强弱按当前币在同窗口有效样本中的排名计算。剔除当前币自身后，做多分数为 `(低于当前币的数量 + 与当前币相等的数量 / 2) / 其他有效币数 × 100`；做空取100减去该值。所有币持平时为50，单样本不可计算。

## 最终输出与缺失

`confidence = round(市场支持 × 0.4 + 多周期方向支持 × 0.3 + 相对强弱 × 0.3)`。

多空两方向均预先计算。提示词只传入文字化结果：五周期状态、结构说明、LONG做多与SHORT做空的最终置信度和环境结论，不传分项分数、内部JSON或新增输出字段。AI按策略选择最终方向并返回对应置信度，不附带IDLE固定置信度说明。

五周期缺失、市场快照过期、任一所需窗口无效或个币排名不可计算时，`available=false`、环境分为 `null`，提示词说明暂无可用分数。程序仅提供文字参考，最终采用AI返回的方向、置信度与理由，不再强制改成IDLE、覆盖置信度或替换理由中的分数。

`coverage`单独记录五窗口有效币数相对已选币数的加权百分比，窗口权重同上，不加入环境分。包括24h在内的任一所需窗口不可计算时，环境分不可用，不对剩余窗口重新分配权重。环境双向拆解和五周期状态保存在分析结果和交易信号的 `environmentContext` 中。

## 与评分的边界

`baseScore`改为策略明确方向条件的满足比例（最高30）；`hardScore`最高50、`softScore`最高20。方向条件不得在硬软条件中重复计分。没有独立方向条件时基础分为0。

市场广度、五周期环境结构、相对强弱不再重复计入评分。策略明确规定的硬性禁入条件仍需检查，评分归属变化不能取消禁入约束。单周期EMA、DI、MACD等入场条件仍按策略评分。

本版权重与档位是固定工程标准，尚未经过收益校准。置信度分布和基础分口径已变化，现有阈值不会自动迁移或修改。
