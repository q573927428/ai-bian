机械稳健共振策略
一、做多 LONG 完整规则
1. 趋势方向判定 EMA50>EMA200
2. 入场硬性条件（全部必须满足）
OI 资金共振：持仓量 OI 变化率 ＞ 0
价格位置合理：当前价格偏离 EMA200 幅度 ≤ 2.5%
成交量放大：当前预计成交量 ≥ 前一根 K 线成交量 × 1.5 倍
ATR 波动率过滤：ATR 波动率 ≥ 0.38%
3. 辅助条件（至少满足 1 项）
A. RSI 有效区间：
35<RSI<65
B. 价格回踩：价格回落至 EMA50 ±1% 区间内
C. K 线形态确认：收实体阳线，且下影线比例 ≤ 0.9%
4. 开仓决策
四项硬性条件全部达标 + 任意 1 项及以上辅助条件满足 → 触发做多开仓
二、做空 SHORT 完整规则
1. 趋势方向判定
EMA50<EMA200
2. 入场硬性条件（全部必须满足）
OI 资金共振：持仓量 OI 变化率 ＜ 0
价格位置合理：当前价格偏离 EMA200 幅度 ≤ 2.5%
成交量放大：当前预计成交量 ≥ 前一根 K 线成交量 × 1.5 倍
ATR 波动率过滤：ATR 波动率 ≥ 0.38%
3. 辅助条件（至少满足 1 项）
A. RSI 有效区间：
35<RSI<65
B. 价格反弹：价格回升至 EMA50 ±1% 区间内
C. K 线形态确认：收实体阴线，且上影线比例 ≤ 0.9%
4. 开仓决策
四项硬性条件全部达标 + 任意 1 项及以上辅助条件满足 → 触发做空开仓
