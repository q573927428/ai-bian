一、做多 LONG 开仓规则（二选一触发，满足任意一个即可）
触发优先级1：金叉预判做多（优先触发）
所有条件必须全部满足，触发后直接开仓，无需判断后续常规信号：
1. 当前价格 ＞ EMA200
2. EMA50 ＜ EMA200
3. EMA间距极度贴近：|EMA50 - EMA200| / EMA200 ＜ 0.18%
触发优先级2：K线信号做多（金叉不满足时触发）
仅当金叉预判做多条件不满足时，判断此信号，所有条件全部满足+任意1个K线信号达标即可开仓：
1. 趋势方向：EMA50 ＞ EMA200
2. K线进度：当前K线完成进度大于30%
3. 价格位置：当前价格位于 EMA200 ±2.5% 区间内
4. K线信号：
① Pin Bar：影线/实体比例 ≥ 3：1，且实体部分最大占比 ≤ 30%（即实体长度不超过整根K线长度的30%）；
②  吞没形态：吞没阳线实体 / 被吞没阴线实体 ≥ 1.6。
