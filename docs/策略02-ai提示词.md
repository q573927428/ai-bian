一、做多 LONG 完整规则
1. 趋势方向：EMA50 > EMA200。
2. 当前K线完成进度大于30%。
3. 当前价格位于 EMA200 ±2.5% 区间内。
4. K线信号：
① Pin Bar：影线/实体比例 ≥ 3：1，且实体部分最大占比 ≤ 30%（即实体长度不超过整根K线长度的30%）；
②  吞没形态：吞没阳线实体 / 被吞没阴线实体 ≥ 1.6。
3. 交易原则：K线信号满足其中一个，就开仓。
