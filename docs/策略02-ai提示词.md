OI资金共振+K线信号交易策略
一、做多 LONG 完整规则
1. 趋势方向：EMA50 > EMA200
2. 共振确认
OI资金共振：持仓量OI变化率 > 0
K线信号（二选一）：
Pin Bar：影线/实体比例 ≥ 3：1，且实体部分最大占比 ≤ 0.3（即实体长度不超过整根K线长度的30%）
吞没形态：吞没阳线实体 / 被吞没阴线实体 ≥ 1.6
3. 交易原则
如果同时满足 “OI资金共振”加上K线信号（二选一满足即可）确认，就开仓。

OI资金共振：持仓量OI变化率 < 0
K线信号（二选一）：
Pin Bar：影线/实体比例 ≥ 3：1，且实体部分最大占比 ≤ 0.3（即实体长度不超过整根K线长度的30%）
吞没形态：吞没阴线实体 / 被吞没阳线实体 ≥ 1.6
3. 交易原则

OI资金共振 + K线信号交易策略
一、做多（LONG）规则
1. 趋势：EMA50 > EMA200
2. 共振与K线：OI变化率>0（OI资金共振），且满足任一K线信号：
- Pin Bar：影线/实体≥3 且 实体长度/K线总长度≤0.3
- 吞没形态：当前阳线实体/前一根阴线实体≥1.6
3. 开仓：上述3个条件同时成立方可开多
二、做空（SHORT）规则
1. 趋势：EMA50 < EMA200
2. 共振与K线：OI变化率<0（OI资金共振），且满足任一K线信号：
- Pin Bar：影线/实体≥3 且 实体长度/K线总长度≤0.3
- 吞没形态：当前阴线实体/前一根阳线实体≥1.6
3. 开仓：上述3个条件同时成立方可开空
