强趋势回调交易策略
一、做多 LONG 完整规则
1. 趋势方向与强度（必须满足）
- 趋势方向：EMA20 > EMA60
- 强度过滤：ADX(14) > 25，禁止开仓
2. 回调入场机会
价格回调至 [EMA60, EMA20] 区间内，且价格位置接近EMA60（优先选择靠近区间下沿的回调点位）。
3. 辅助共振确认
- RSI指标：RSI < 65
- OI资金共振：持仓量OI变化率 > 0
- K线信号：在回调入场区域出现反转K线（如看涨吞没形态、锤子线或长下影Pin Bar）
4. 交易原则
如果同时满足 “强趋势（方向+强度）+ 回调区域 + OI资金共振” 三大核心要素，RSI和K线信号作为辅助确认，就开仓。
二、做空 SHORT 完整规则
1. 趋势方向与强度（必须满足）
- 趋势方向：EMA20 < EMA60
- 强度过滤：ADX(14) > 25，禁止开仓
2. 回调入场机会
价格反弹至 [EMA20, EMA60] 区间内，且价格位置接近EMA60（优先选择靠近区间上沿的反弹点位）。
3. 辅助共振确认
- RSI指标：RSI > 35
- OI资金共振：持仓量OI变化率 < 0
- K线信号：在反弹入场区域出现反转K线（如看跌吞没形态、流星线或长上影Pin Bar）
4. 交易原则
如果同时满足 “强趋势（方向+强度）+ 回调区域 + OI资金共振” 三大核心要素，RSI和K线信号作为辅助确认，就开仓。
